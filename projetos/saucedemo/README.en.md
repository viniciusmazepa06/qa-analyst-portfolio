# QA Practice Project — SauceDemo

This project documents the planning and execution of manual tests on a demo e-commerce application.

- **Application:** [SauceDemo / Swag Labs](https://www.saucedemo.com/)
- **Type:** Manual functional testing (black-box)
- **Status:** Execution preparation

## Objective

Validate the store's main user journeys: authentication, product catalog, sorting, shopping cart, and checkout. The project demonstrates test analysis, structured execution, evidence collection, and defect communication.

## Environment

- Browser and version: to be recorded during execution
- Operating system: to be recorded during execution
- Execution date: to be recorded during execution
- Demo username: `standard_user`
- Public demo password: `secret_sauce`

Use these credentials only on the public demo website. Never use or publish personal passwords.

## Scope

- Valid, invalid, and locked-out login
- Product listing and sorting
- Add and remove cart items
- Checkout required-field validation
- Order review and completion
- Logout

Real payments, real personal data, load testing, and security testing are out of scope.

## Result integrity

All test cases start as **Not executed**. Results, defects, and evidence will only be recorded after they are observed in the live demo environment. An intentional demo-account limitation will not automatically be classified as a defect.
