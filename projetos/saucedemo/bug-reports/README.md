# Relatórios de Defeitos — SauceDemo

Nenhum defeito foi confirmado nesta etapa.

Um comportamento só será registrado como defeito após:
1. Execução do cenário em ambiente identificado.
2. Comparação entre resultado esperado e resultado observado.
3. Repetição suficiente para confirmar a reprodução.
4. Verificação de que não se trata de comportamento intencional da conta de demonstração.

## Relatórios

Os relatórios confirmados serão adicionados nesta pasta usando o arquivo [modelo de bug report](bug-report-template.md).
